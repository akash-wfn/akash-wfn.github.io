# Akash Krishna - Personal Website

This is the code repository for my personal academic and professional website, live at [akashkrishna.org](https://akashkrishna.org).

## About This Project

This website is a customized version of the academic website template generously provided by the [Allan Lab at Leiden University](https://www.allanlab.org/aboutwebsite.html).

## Technologies Used

* **Static Site Generator**: [Jekyll](https://jekyllrb.com/)
* **Content**: Markdown (`.md`) and YAML (`.yml`) files
* **Styling**: SCSS and Bootstrap
* **Hosting**: [GitHub Pages](https://pages.github.com/)
